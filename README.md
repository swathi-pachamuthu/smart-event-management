# Smart Event Management System

A full-stack web application designed to simplify the management of college events by providing separate functionalities for administrators and participants.

## Features

- User registration and login
- Secure authentication
- Role-based access for Admin and Participants
- Event creation and management
- Event browsing and participation
- Admin dashboard
- Participant dashboard
- Event image/file upload support
- Responsive web interface

## Technologies Used

### Frontend
- React.js
- HTML
- CSS
- Bootstrap

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Authentication & Other Tools
- JWT
- bcrypt
- Multer
- Axios
- Git & GitHub
